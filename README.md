# AutoDecision AI

**نظام دعم القرار الذكي لاختيار السيارة المناسبة** — تطبيق ويب عربي (RTL) بواجهة أمامية وخادم محلي وقاعدة بيانات SQLite دائمة.

## فكرة المشروع
يساعد النظام المستخدم على تحديد متطلباته (الميزانية، الاستخدام، عدد أفراد الأسرة، المسافة السنوية، نوع المحرك، وأوزان الأولويات)، ثم يحسب درجة توافق للسيارات ويرتب أفضل الخيارات مع تفسير أسباب الترشيح. يمكن للمستخدم مراجعة المقارنة وسجل قراراته السابقة.

## التقنيات
- Frontend: HTML5, CSS3, JavaScript (Vanilla) مع واجهة عربية RTL متجاوبة.
- Backend: Node.js HTTP server وواجهات REST API.
- Database: SQLite باستخدام `node:sqlite` المدمج في Node.js 22.5+ (لا تحتاج تثبيت حزمة قاعدة بيانات خارجية).
- Authentication: كلمات المرور محفوظة بتجزئة scrypt مع salt عشوائي، وجلسات Bearer tokens مخزنة كـ SHA-256 hashes.

## المتطلبات
- Node.js 22.5 أو أحدث (يفضل Node.js 24 LTS).
- Windows 10/11 أو macOS أو Linux.
- لا يتطلب API key أو اتصالاً بخدمة ذكاء اصطناعي خارجية.

## التشغيل على Windows PowerShell
1. فك ضغط مجلد المشروع.
2. افتح PowerShell داخل مجلد `AutoDecision-AI`.
3. تحقق من إصدار Node:

   ```powershell
   node -v
   ```

4. شغّل الخادم:

   ```powershell
   npm start
   ```

5. افتح المتصفح على: http://localhost:3000

لإيقاف الخادم اضغط `Ctrl + C` في PowerShell.

## حساب التجربة
- البريد: `demo@autodecision.ai`
- كلمة المرور: `123456`

هذا حساب عرض محلي يُنشأ تلقائياً عند أول تشغيل إذا لم يكن موجوداً. أنشئ حسابك الخاص من واجهة التسجيل أيضاً. لا تستخدم كلمة المرور الافتراضية في نشر عام.

## إنشاء حساب مشرف (اختياري)
يمكن إعداد حساب مشرف من PowerShell قبل تشغيل الخادم:

```powershell
$env:ADMIN_EMAIL = "admin@example.com"
$env:ADMIN_PASSWORD = "ChangeThisPassword123!"
npm start
```

يُنشأ الحساب بصلاحية `admin` إذا لم يكن موجوداً. واجهة API الخاصة بإحصاءات الإدارة وإضافة السيارات محمية بهذه الصلاحية. لا تشارك بيانات المشرف.

## قاعدة البيانات
تُنشأ تلقائياً في `database/autodecision.db` عند أول تشغيل. الجداول:

| الجدول | الغرض |
|---|---|
| `users` | حسابات المستخدمين وكلمات المرور المجزأة والأدوار |
| `sessions` | جلسات الدخول وتواريخ انتهائها |
| `cars` | بيانات السيارات المستخدمة في التحليل |
| `recommendations` | السيارات المرشحة ودرجاتها وأسبابها |
| `decision_history` | مدخلات كل تحليل ونتائجه المحفوظة |
| `comparisons` | سجل عمليات المقارنة |
| `favorites` | السيارات المفضلة لكل مستخدم |

ملف `database/schema.sql` يحتوي تعريف الجداول والفهارس، و`database/seed.json` يحتوي بيانات السيارات الابتدائية. ملف قاعدة البيانات نفسه لا يُضمّن في الحزمة؛ ينشأ تلقائياً على جهاز التشغيل.

## آلية اتخاذ القرار
يستخدم النظام أسلوب **Weighted Scoring**:
1. تُقرأ أوزان السعر والأمان والاعتمادية والاقتصاد والراحة والأداء (من 1 إلى 5).
2. تُحوّل قيمة السعر إلى درجة نسبية بحسب ميزانية المستخدم، بينما تستخدم درجات الخصائص الأخرى من 10.
3. يُحسب المتوسط الموزون بعد تطبيع مجموع الأوزان.
4. تضاف ملاءمة الاستخدام (مدينة/سفر/مختلط)، مع مراعاة المسافة السنوية.
5. تؤثر ملاءمة عدد المقاعد ونوع المحرك والميزانية على النتيجة النهائية.
6. تُرتّب السيارات حسب درجة التوافق، ثم تُحفظ أفضل أربع نتائج في قاعدة البيانات مع أسباب الترشيح.

هذه خوارزمية دعم قرار تفسيرية وليست نموذج تعلم آلي مدرّباً. يجب أن تكون أوزان المعايير وتقييمات السيارات قابلة للتحديث والتحقق.

## البيانات وحدودها
بيانات السيارات والأسعار والتقييمات المرفقة **بيانات تعليمية/تقديرية لأغراض تجربة النظام** وليست عرض أسعار رسمياً أو تقييماً مستقلاً موثقاً. يجب تحديثها والتحقق منها من الوكلاء والمصادر الرسمية قبل استخدامها لاتخاذ قرار شراء حقيقي. النتائج تعتمد على جودة المدخلات ولا تمثل توصية تجارية ملزمة.

## الاختبار
شغّل الخادم في نافذة PowerShell، ثم افتح نافذة ثانية داخل مجلد المشروع ونفّذ:

```powershell
npm test
```

يختبر السكربت فحص الخدمة، إنشاء حساب، تنفيذ التحليل، حفظ النتيجة في SQLite، قراءة السجل، وإحصاءات الملف الشخصي.

## واجهات API الأساسية
- `GET /api/health` — حالة الخدمة.
- `POST /api/auth/signup` — إنشاء حساب.
- `POST /api/auth/login` — تسجيل الدخول.
- `GET /api/auth/me` — المستخدم الحالي.
- `POST /api/auth/logout` — إنهاء الجلسة.
- `GET /api/cars` — قائمة السيارات.
- `POST /api/analyze` — تنفيذ التحليل وحفظه.
- `GET /api/history` — سجل المستخدم الحالي.
- `DELETE /api/history/:id` — حذف تحليل من سجل صاحبه.
- `GET /api/profile` — ملخص الملف الشخصي.
- `GET/POST/DELETE /api/favorites` — إدارة المفضلة.
- `GET /api/admin/stats` و`POST /api/admin/cars` — عمليات مشرف محمية.
